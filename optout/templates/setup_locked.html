Open the setup link from the logs

This install doesn't have an admin yet. To make sure nobody else on your network claims it, setup needs the one-time link the app printed when it started.

Find it in the container log
docker compose logs app | grep "Setup URL"

In Portainer: Containers → fletcher-fortis → Logs. The link looks like http://…/setup?token=… and changes on every restart.
